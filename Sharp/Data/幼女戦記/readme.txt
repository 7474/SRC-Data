# 短機関銃はアンソン->ターニャの優遇武器にする。
#
# 見直したところ（2026-10）
# ・拳銃は使う場面が少なく、主力の銃（自動小銃・短機関銃）で足りるので外した。
# ・魔導刃は魔力を纏わせた銃剣で、切り払える近接武器なので「突」ではなく「武」にした。
# ・マップ兵器は、作品の大きな特色なので残す（docs/データ作成ガイドライン.md の「5.3 マップ兵器屋」として作る）。
# 　空間爆撃術式（ターニャ）：九五式で広域を焼き払う。投下型の半径2、気力110・ＥＮ50。作中で友軍に退避を警告するので、敵味方は識別しない。
# 　　ボス戦の一撃より、マップ兵器の使い勝手で個性を出す（単体向けの切り札は持たせない）。
# 　　GSC 拡張の投下型の半径2のマップ兵器（攻撃するもの 229 件）と比べた（2026-10）。
# 　　ユニットの経験値 180-199 の帯で識別しないものは、攻撃力 1400〜1900（中央値 1600）、ＥＮの中央値 70、気力の中央値 120。
# 　　攻撃力は中央値より少し低く、ＥＮ・気力の条件は軽い。ほかの主人公格のもの（なのは・フェイトのブラストカラミティ 2000、
# 　　高原日勝の大激怒岩盤割り 2300 など）は攻撃力が高いが、気力130以上・ＥＮ120・弾数1・合体技などの重い条件が付く。
# 　　ターニャのものは一撃は劣るが、1 回の出撃で 3 回撃てるので、マップ兵器の使い勝手で上回る。
# 　空間光学術式（メアリー）：加護による膨大な魔力で撃つ光学術式。直線のビームで、取り回しが悪い
# 　　（敵味方を識別しない・気力130・ＥＮ120 で 2 回まで）。
