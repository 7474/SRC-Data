# 　（GSC データパック 拡張 28,618 体のうち、HP の 99.8%、ＥＮの 99.1%、装甲の 97.8%、運動性の 99.9% がこの刻み）
# 短機関銃はアンソン->ターニャの優遇武器にする。
#
# 見直したところ（2026-10）
# ・拳銃は使う場面が少なく、主力の銃（自動小銃・短機関銃）で足りるので外した。
# ・魔導刃は魔力を纏わせた銃剣で、切り払える近接武器なので「突」ではなく「武」にした。
# ・空間爆撃術式（マップ兵器）・空間光学術式（直線のマップ兵器）は、等身大でマップ兵器を安易に付けない
# 　ガイドライン（docs/データ作成ガイドライン.md「MAP兵器の扱い（等身大基準）」）に合わせ、
# 　遠射程の通常武器（九五式爆裂術式・大出力術式）に置き換えた。
# 　九五式爆裂術式はターニャ（九五式の全力）、大出力術式はメアリー（加護による膨大な魔力）の切り札。
# 　メアリーは火力を上げるＳＰ（熱血・魂）を持たないので、ユニットのパワーで押すよう最終奥義の範囲（2200、気力130・ＥＮ80）にした。

## 調べた情報（2026-10）

# https://ja.wikipedia.org/wiki/%E5%B9%BC%E5%A5%B3%E6%88%A6%E8%A8%98 （登場人物・用語）
# https://www.weblio.jp/wkpja/content/%E5%B9%BC%E5%A5%B3%E6%88%A6%E8%A8%98_%E7%94%A8%E8%AA%9E （技術・兵器）
# https://www.shurigekijou.com/youjo-senki-computation-orb-guide/ （演算宝珠）
#
# ・アンソン＝スーは協商連合の大佐。メアリー＝スーは協商連合出身で、合州国の義勇軍の少尉。
# ・ドレイクは連合王国の海兵魔導部隊の中佐。ミケルは連邦の大佐で防御の術式に長ける。
# ・ビアントは共和国 特殊作戦軍の魔導中隊の司令（中佐）。
# ・エレニウム九五式は四核同調の試作品で量産できない。九七式は双発型で、実質的に第二〇三大隊専用。
# ・帝国のエレニウム系は高性能だが燃費が悪い。連邦の宝珠は攻撃・防御に絞り、調達しやすくしている。
# ・飛行補助装置は国ごとに違う（共和国は木馬型、連合王国は箒型）。
# ・連邦では魔導師が迫害されてきた。
