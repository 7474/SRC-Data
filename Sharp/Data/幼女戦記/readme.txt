# https://ja.wikipedia.org/wiki/%E5%B9%BC%E5%A5%B3%E6%88%A6%E8%A8%98 （登場人物・用語）

# ・帝国のエレニウム系は高性能だが燃費が悪い。連邦の宝珠は攻撃・防御に絞り、調達しやすくしている。

# 格はデータに書かれていないので、主人公格・準主役格がはっきりしている作品のキャラと比べた。

# これに合わせて決めたこと
# ・ターニャ：経験値180、合計942（主人公格の上端）、ＳＰ60。

# ・ザコ・汎用：GSC の実態の範囲にした（国ごとの練度の差は残した）。
# ・ユニットの HP は、同じ帯の GSC の下位10%未満だったので引き上げた（防殻のぶん、まだ低め）。
