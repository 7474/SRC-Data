# memo:
# 大学卒業時にフォンが付くが割愛。
# 迎撃よりは切り払いをしている。
# 格闘：実際どうかはともかく同じ近接武器を使った際のイメージ重視で格闘はほどほどにしておく。
# 射撃：最高クラスの魔術師だが唯一無二ではない
# 命中：とてもよく当てる
# 回避：とてもよく避ける
# 技量：とても高い
# 反応：主人公補正で高くてよいのでは
# 性格：前世の合理主義で動き、戦闘を好むわけではないので普通。
# 指揮：大隊長（後に戦闘団長）。部下（汎用の大隊員）を率いる。
# ＳＰ: 偵察は実質使わないので、序盤から機動戦に使える加速にした。
# 　忍耐は生き延びることを最優先する性分（GSC で持つのは経験値 180 以上の 6%）。
# 　集中と忍耐の両方を持つのは 2% で、奇襲のひらめきと合わせると生き残りに寄りすぎるので、集中は必中にした。
# 　必中は空間爆撃術式（命中補正 +0）を確実に当てる用途。狙撃（射程+1）は空間爆撃術式の射程も延ばし、マップ兵器屋の役どころに合う。
# 　奇襲（加速・必中・熱血・ひらめき）が終盤の切り札。
