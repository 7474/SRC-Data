# アニメ版（TV アニメ・劇場版）

# 航空魔導師は「空も飛べる歩兵」。航空機より遅く、戦車より装甲が薄いが、防殻で堅く守る。
# 　→ 全員リアル系。移動力 4（空陸）、防殻術式（フィールドLv1。近接攻撃には無効）。
# 武器は readme.txt のひな形から、各国の演算宝珠と練度に合わせて選ぶ。
#
# 各国の演算宝珠と練度（ユニットの性能に表す）
# 　第二〇三大隊：エレニウム九七式（双発）。高性能だが燃費が悪い → ＥＮ・術式の攻撃力が高い
# 　帝国（一般）：大隊より旧式の宝珠。訓練の水準は高い → 性能は標準。術式の攻撃力は大隊より低い
# 　協商連合　　：小国で装備が限られる → 全般に低め
# 　共和国　　　：木馬型の飛行補助装置。数で対抗する → 運動性低め、術式の攻撃力低め
# 　連合王国　　：箒型の飛行補助装置。海兵魔導師 → 海の適応 B、堅実
# 　連邦　　　　：攻撃・防御に絞り、調達しやすくした宝珠 → 装甲・HP 高め、ＥＮ・運動性低め、射撃の命中低め
# 　合州国　　　：資源が豊かで装備が充実 → 弾数が多く、銃の攻撃力が高め
