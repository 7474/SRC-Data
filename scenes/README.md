# 場面のカタログ

7474/SRC の SRC#Studio の「かんたん作成」が読む、場面のサンプル（マップと、おすすめの置く位置。作品の場面なら作品・ユニット・セリフも）です。書式は 7474/SRC の [docs/tools/quick-create.md](https://github.com/7474/SRC/blob/master/docs/tools/quick-create.md) の「場面のカタログ」。SRC#Studio は `https://raw.githubusercontent.com/7474/SRC-Data/master/scenes/index.json` を読みます。

| ファイル | 中身 |
|---|---|
| `index.json` | 場面の一覧（`make.py` が書く） |
| `maps/*.map` | マップ（`make.py` が書く） |
| `make.py` | 場面とマップを作るスクリプト。場面を足す・直すときはここを直して `python3 scenes/make.py` |
| `check.py` | 確かめ（CI の `Validate Scenes`）。作り直しても変わらない・地形が最小の汎用データにある・置く位置がマップの中・ユニットとパイロットが作品のデータにある・話す人が置いたパイロット |

## 決まり

- マップは SRC# の最小の汎用データ（7474/SRC の `SRC.Sharp/Content/basic-data`）の地形だけを使う。どのサイトの SRC#Web でも出せるようにするため。宇宙・月面の地形（宇宙空間・暗礁空間・残骸・コロニー・宇宙要塞・宇宙ドック・地球・月・月面・クレーター(小)・月面都市・月面基地）も入っている（番号は汎用データと同じ）
- ユニット・パイロットは GSC データパックの名前（`index.json` の作品）。強さは、かんたん作成で作ったシナリオを 7474/SRC の `srcsharp play` で自動で遊び、25 ターンまでに勝てることで確かめた
- セリフはこのカタログのために書いた短い文。原作の台詞を長く写さない
