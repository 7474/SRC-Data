# 場面のカタログ

7474/SRC の SRC#Studio の「かんたん作成」が読む、場面のサンプル（マップと、おすすめの置く位置。作品の場面なら作品・ユニット・セリフも）です。書式は 7474/SRC の [docs/tools/quick-create.md](https://github.com/7474/SRC/blob/master/docs/tools/quick-create.md) の「場面のカタログ」。SRC#Studio は `https://raw.githubusercontent.com/7474/SRC-Data/master/scenes/index.json` を読みます。

| ファイル | 中身 |
|---|---|
| `index.json` | 場面の一覧（`make.py` が書く） |
| `maps/*.map` | マップ（`make.py` が書く） |
| `make.py` | 場面とマップを作るスクリプト。場面を足す・直すときはここを直して `python3 scenes/make.py` |
| `check.py` | 確かめ（CI の `Validate Scenes`）。作り直しても変わらない・地形が最小の汎用データにある・置く位置がマップの中・ユニットとパイロットが作品のデータにある・話す人が置いたパイロット |

## 場面

作品の場面は、SRC らしく別の作品のゲストが味方にも敵にも入る（スパロボのような共演）。ロボット（GSC データパックのロボ）の場面と、等身大（GSC データパックの拡張。生身のキャラクター）の場面がある。等身大の場面にはタグ「等身大」を付ける。

レベルはスパロボ・SRC の慣習に合わせる。パイロットのレベルに極端な差は付けず、敵を味方より少し高くする。各場面のレベル帯 L は原作のどの時期の話かで決める。序盤は 5〜15、中盤の山場は 30 に届かない程度（27 前後）、終盤は 35〜40、最終盤は 50 前後（48）。そのうえで、味方は L、敵のザコは L+1、名前のある敵は L+2、ボスは L+3 にする。ただし、機体がとても強いボス（ビグ・ザム・ジオング・試作２号機）は L+1〜L+2 にした（`make.py` の各場面の注釈）。

強敵（原作のボス・ライバル）には `bossRank`（SRC の `BossRank`）を付ける。ランクは付けない（0）。レベルを慣習に合わせたうえで勝てるよう、多くのボスは 0 にした。0 でも、ボスとして扱われ（状態異常の一部が効かない）、傷ついても下がらずに戦い続ける（ボスでない敵は下がって回復するので、勝負がつかなくなる）。

強さは、かんたん作成で作ったシナリオを 7474/SRC の `srcsharp play` で乱数を変えて 5 回ずつ自動で遊んで確かめた。勝ったときのセリフが出たら勝ち、味方が全滅したら負けとして数える。自動で遊ぶ AI はエースが一機で突っ込みがちなので、人が遊ぶよりは負けやすい。勝てないときは、味方のレベルは上げずに、ボスランク、敵の数、原作で同じ場にいた仲間を足す、置く位置を散らす、で合わせた。

## 決まり

- マップは SRC# の最小の汎用データ（7474/SRC の `SRC.Sharp/Content/basic-data`）の地形だけを使う。どのサイトの SRC#Web でも出せるようにするため。宇宙・月面の地形（宇宙空間・暗礁空間・残骸・コロニー・宇宙要塞・宇宙ドック・地球・月・月面・クレーター(小)・月面都市・月面基地）も入っている（番号は汎用データと同じ）
- ユニット・パイロットは GSC データパックの名前（`index.json` の作品）。原作の機体・人物の組み合わせ（例: ア・バオア・クーのシャアはジオング、ソロモンのスレッガーはＧファイター）を基本に、ゲストは原作どうしのつながりや、ファンが「おっ」と思う顔合わせ（あしゅら男爵とシャアの共闘、ソロモンのガトー、マックスとミリア、アクシズを押すガンバスターなど）で選ぶ
- セリフはこのカタログのために書いた短い文。原作の台詞を長く写さない
